# v0.16.0 — Local MIDI collection import

This release turns local MIDI ingestion into a list-first Sheet Library workflow.

A normal Windows user can:

- click **Import MIDI...** and multi-select `.mid` / `.midi` files;
- click **Import MIDI Folder...** to discover MIDI files recursively;
- drag supported files or folders onto the Library;
- see every valid imported source become a persistent Library row;
- search by song/file/type and see a dedicated Type column;
- import a collection again without creating content-identical duplicate rows.

Batch import validates every candidate through the existing deterministic production loader before copy, sorts candidates deterministically, deduplicates by SHA-256 against valid managed content, reports partial failures without discarding successful imports, and enforces a 2000-candidate safety bound.

The existing low-level single-file `Import` collision behavior remains intact for compatibility. Legacy TXT/VPS, MusicXML repeat handling, MIDI canonical timing, Legacy/Legacy x2 playback, Roblox exact-window focus, virtual-key dispatch, cancellation and release-all safety are unchanged.

This phase does **not** transcribe recorded audio such as MP3/WAV/FLAC into MIDI. That requires a separate deterministic MIR/transcription production phase.
